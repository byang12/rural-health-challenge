Course 1 · Topic 2 of 6

Identify sources and collection methods

Reading time: about 4 minutes

In this topic

Match each required field to a source you actually have and are allowed to use, and tell extraction apart from collecting new information.

For your project: you fill in the source catalog and the method and access details of your capture plan.

Key terms
Source catalog
A list of every source you use, each with a stable ID, version, location, and a statement of what it covers.
Extraction
Taking information out of material that already exists, such as a referral packet or a log.
New collection
Gathering information that does not exist yet, for example by asking people questions.
Evidence category
What kind of source something is. In this course: published public context, or synthetic teaching material.
Capture date
The day you actually collected the information. It is different from the dates the source describes.

A list of possible sources is not evidence

Before using AI, find out which materials you actually have, what they describe, and whether you are allowed to use them for the exercise. In this case, the published article explains the research context, the synthetic packets and logs give practice information, and the role cards support a simulated interview.

A future partner record is only a proposed source until it is obtained through the proper process. In this program, organizers coordinate any contact with partners.

Start a small source catalog

For each source, record:

  • a stable identifier, a descriptive title, and a version or release;
  • where it is, and what it covers;
  • its evidence category and any access conditions.

For a document, keep the original file and note the page or labeled line you used. For a role-play response, keep the question, the respondent’s role, and the response text.

Record the date you actually captured the information separately from the period the source describes. A synthetic event dated October 9 is not evidence that you did the extraction that day.

Each problem uses a different method

Collection method for each problem
ProblemMethodWhat AI does
1. PacketsExtraction: the packets already exist.Pulls out specified items and checks them against a supplied teaching checklist.
2. Event logExtraction: the log already exists.Turns written event statements into structured rows.
3. Follow-up rolesNew collection: an interview guide; people give the answers.Organizes recorded answers. In the short course, written response cards stand in for interviews and stay labeled synthetic.

AI must never produce pretend staff answers and label them as collected evidence.

A source supports some fields, not others

  • The article supports a statement about reported communication problems. It does not supply the booking date of the fictional referral PKT-A.
  • A role card reports one person’s view of who is responsible. It is not an approved operating policy.
  • A cover sheet saying that a summary is attached does not prove the summary is among the supplied files.

Write these distinctions into the catalog and the collection instructions, so a reader does not have to guess them later.

Test what the AI can actually read

Use AI to draft the map from sources to fields and to point out gaps. Then inspect the real materials yourself. The approved task does not give a tool access to a missing attachment, an outside system, or a partner’s records.

Test access with the supplied synthetic text: ask the tool to return a named source identifier and one supporting line. If it cannot read a file, record that limitation instead of accepting a summary that only sounds right. If file reading does not work, paste the permitted labeled text instead.

Data use with AI tools

Use only the supplied public context and synthetic administrative materials. Do not upload real patient information or restricted partner records to an unapproved service. Keep missing sources visible as pending requests or documented gaps, each with a proposed next step. Documenting a source describes how information was obtained; it does not give you permission to access it.

AI instruction for this stage

Prompt to adapt: map sources to fields

Create a source-to-field map for the selected task using only the listed materials. For each source, record ID, title, version, exact location, scope, evidence category, access status, and the fields it can support. Separate proposed but unavailable sources. Do not claim to have opened a file unless its contents are accessible. Do not generate interview answers.

Practice activity

Try it: Workpad A

Check one source entry against the actual source card. Add its method and evidence category to Workpad A, and record one limitation of that source.

Check your understanding

The article discusses gaps in referral information. Can it supply PKT-A’s booking date?

  1. Yes, because the problem is based on the literature.
  2. No; that value must come from the supplied packet or log.
  3. Yes, if AI gives a confident estimate.
Show the answer

Answer: B. The article is context. The fictional operating record is a separate source.

A confuses the reason for studying a problem with the record needed to answer a specific question. A confident answer (C) is not a source.
